Sistema de Renta de Videos - MongoDB
Descripción
Este proyecto implementa una base de datos NoSQL utilizando MongoDB para administrar un sistema de renta de videos.

El sistema permite registrar clientes, películas, empleados, alquileres y devoluciones.

Tecnologías utilizadas
MongoDB

MongoDB Shell (mongosh)

JavaScript

Visual Studio Code

Git y GitHub

Estructura de la base de datos
La base de datos se llama renta_videos y contiene cinco colecciones:

clientes

peliculas

empleados

alquileres

devoluciones
